# Bruce Documentation and Copy

- The `writer` prepares new user-facing copy for the README, LCD, CLI, or WebUI. Preserve menu item labels, localization keys, placeholders, and meaning. For strings embedded in code, send the text and insertion point to the `embed-engineer` through the primary agent. The technical owner checks length, encoding, and rendering.
- The `archivist` maintains existing documentation and navigation. Before moving information, identify the canonical source, all inbound links, and the file owner. Update links within the scope of the assignment. Preserve information readers still need, even if the original section is outdated.
- Use the user's language and established terminology. Start with the outcome or action. Support claims about firmware capabilities with verifiable commands, files, and test results. Distinguish confirmed behavior from planned behavior and hardware verification from build verification.
- Use relative paths for links within the repository. Verify the targets and existing anchors. Send working notes and questions to the orchestrator separately from the finished copy.
